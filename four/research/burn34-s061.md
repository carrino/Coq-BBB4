# S061: mutually recursive binary words

This isolated package proves `NonHalt` and `QHBound 0` for exact frozen S061:

```text
1LB2LB3RA1RA_3RB2LA1RA3LB
```

The complete vector is `[5;9;14;6;15;8;6;13]`; the census code is 5491873516.
The native checker independently decodes row 61 of the frozen 78-row file.
The Coq wrapper proves complete-table equality, the bound for every completion,
and an exact singleton inventory. The prior remaining-8 snapshot is pinned
separately; this package does not change the tracker.

Write `C(k,w)` for A scanning blank with nearest-first left word `3^k w`
and empty right word. Every grammar word below uses only symbols 1 and 3.
The exact blank run reaches `C(1,1)` in five steps.

The invariant uses two types of finite trees, `s61_even` and `s61_odd`.
Their constructors are E0 through E5 and O0 through O5. Each nonconstant
constructor has one child. Four mutually recursive functions produce the
words `E(e)`, `O(o)`, `Ne(e)` and `No(o)`. Their definitions are:

| Constructor | Word | Normalized word |
| --- | --- | --- |
| E0 | 131 | 311 |
| E1 | 1113 | 3331 |
| E2(o) | 11113 O(o) | 33331 No(o) |
| E3(e) | 13331 Ne(e) | 31331 Ne(e) |
| E4(e) | 11131 Ne(e) | 33311 Ne(e) |
| E5(o) | 13313 O(o) | 31313 O(o) |
| O0 | 1 | 331 |
| O1 | 1313 | 3113 |
| O2(e) | 11113 E(e) | 33331 Ne(e) |
| O3(e) | 13131 Ne(e) | 31131 Ne(e) |
| O4(o) | 11133 O(o) | 33313 O(o) |
| O5(o) | 13113 O(o) | 31113 O(o) |

Concatenation is implicit in the table. Coq checks that every recursive
function call uses a strict child of its argument. There is no assumed
infinite word, normalization oracle, or unproved word-closure condition.

A normalizer starts B on the nearest cell of a left word and returns A
reading the first cell of an untouched right context. For every finite tree
and arbitrary right context r, the core proves:

```coq
csteps tm (ec e) (back B (E e) r) = Some (front A (Ne e) r)
csteps tm (oc o) (back B (O o) r) = Some (front A (No o) r)
```

Both normalized words start with 3. Normalizer costs by constructor are
`ec=[3,7,10+oc(child),3,7,3]` and
`oc=[7,3,10+ec(child),3,7,3]`. The recursive wrapper consumes the fixed
prefix 11113, invokes its child's normalizer with an explicit right context,
and reconstructs a 33331 prefix, adding ten steps.

A second normalizer theorem proves, for every even tree:

```coq
csteps tm (dc e) (back B (Ne e) r) =
 Some (front A (O (en e)) r).
```

Its costs are `dc=[7,13,11,5,10+dc(child),5]`. The only recursive case
normalizes `33311 Ne(child)`. A five-step prefix program reaches the child's
normalized word; its recursive double normalizer runs with right context
`22333r`; a five-step right scan reconstructs `11133 O(en(child))`.
The child is strictly smaller, so this is an ordinary structural induction.

The successor maps are finite constructor operations:

| Odd constructor o | on(o) |
| --- | --- |
| O0 | E0 |
| O1 | E1 |
| O2(e) | E3(e) |
| O3(e) | E4(e) |
| O4(o) | E5(o) |
| O5(o) | E2(o) |

| Even constructor e | en(e) |
| --- | --- |
| E0 | O1 |
| E1 | O4(O0) |
| E2(o) | O2(on(o)) |
| E3(e) | O3(e) |
| E4(e) | O4(en(e)) |
| E5(o) | O5(o) |

Here en recurses only through the child of E4. The identity
`E(on(o)) = 1 :: tail(No(o))` holds for every odd tree by case analysis.

These normalizers give the two main returns:

```text
C(2j+1,O(o)) -> C(2j+2,E(on(o)))
  in 4(2j+1)+oc(o)+4 steps
C(2j+2,E(e)) -> C(2j+3,O(en(e)))
  in 4(2j+2)+ec(e)+dc(e)+3 steps
```

Both statements hold for every natural j and every finite tree. Starting
from a main cut, A writes a new rightmost 1 and enters B. B scans the leading
threes and invokes the first normalizer. A scans right through those threes,
writing ones. The rightmost marker 1 turns A back left; each pair of ones
moves left in A/B and writes two twos. For odd k, A reaches the initial 3
of the normalized word, turns right, and restores the k+1 leading threes.
For even k, B instead invokes the double normalizer before the final right
scan. The arbitrary right contexts in the normalizer theorems account for
all intermediate twos and threes exactly.

Composing both returns gives an unconditional positive cycle from
`C(2j+1,O(o))` to `C(2(j+1)+1,O(en(on(o))))`. The actual entry is the odd
main with j=0 and O0. Induction therefore gives arbitrarily late A visits.
The first step after every main visit is in B, giving arbitrarily late B
visits. Totality proves nonhalting; recurrence of both states proves the
state bound zero. No coarse parity checksum or unrestricted binary-word
closure is assumed. In particular, an odd grammar word placed at an even
prefix length need not satisfy the return.

Forty Coq regressions check all twelve constructor normalizers, all six
double-normalizer boundary cases and a deeper recursive case, both parity
returns for all constructors, positive longer-prefix cycles, actual blank
entry, grammar/parity negative controls and exact A1/B3 transitions.
The 12,756 native controls independently replay all grammar trees through
depth three (170 of each type), right contexts through length two, matching
prefix parities, composed cycles, entry and 64 consecutive actual cycles.
Changing A1's target from B to A or reversing B3's direction invalidates
the claimed cycle. These finite controls supply no universal proof credit.
