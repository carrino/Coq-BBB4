# S076: a recursive grammar at the left blank boundary

This isolated package proves `NonHalt` and `QHBound 0` for exact frozen S076:

```text
1LB2RB1RB2LB_2RB3RA1LA0LB
```

Its complete vector is `[5;11;7;9;11;14;4;1]`, with census code 527732110.
The native checker independently decodes frozen row 76. The Coq wrappers
prove complete-table equality, the state bound for every completion, exact
singleton census membership, and that the family was previously pending.
The prior remaining-5 snapshot was captured before S015's registration and
is pinned unchanged. This package does not edit the tracker.

Let `U=1001010`, `P=110`, and write all tape words nearest-first. A main
configuration has A scanning 0, empty left word, and right word `U P^n w`.
The invariant requires n>0 and w in the finite recursive grammar below.
The exact blank run reaches n=1 and the second grammar base at step 234.

The grammar is most readable in one-run notation. A run list
`[r0,r1,...,rt]` denotes `1^r0 0 1^r1 0 ... 0 1^rt`. These numbers are
run lengths, not tape symbols. Every encoded word uses only 0 and 1.
There are six base trees:

| Tree | Run list |
| --- | --- |
| G0 | [1,1,1,3] |
| G1 | [4,1,3] |
| G2 | [1,2,6] |
| G3 | [5,6] |
| G4 | [1,1,9] |
| G5 | [4,9] |

Four constructors take a natural m and a smaller tree g. They prepend the
following run lists before the child's run list; `2^m` means m copies of
the run length 2:

| Constructor | Prepended run lengths |
| --- | --- |
| W0(m,g) | [1,2,1] ++ 2^m |
| W1(m,g) | [5,1] ++ 2^m |
| W2(m,g) | [1,1,4] ++ 2^m |
| W3(m,g) | [4,4] ++ 2^m |

The successor maps G0 through G5 in order, then G5 to W0(0,G0).
W0 maps to W1, W1 to W2, and W2 to W3 with the same parameters.
W3(m,g) maps to W0(m+1,next(g)). This final case recurses only on the
strict child g. Coq's inductive tree and guarded recursive function provide
a finite representation of every reachable word.

The induced run operation F has these context rules:

```text
[1,1] u -> [4] u
[1,2] u -> [5] u
[5,1] u -> [1,1,4] u
[2] u   -> [2] F(u)
[4] u   -> [1,2] F(u)
```

Its terminal rules are `[1,3]->[6]`, `[1,6]->[9]`,
`[5,6]->[1,1,9]`, `[3]->[1,3]` and `[9]->[1,1,1,1,3]`.
These are an indexed inductive relation in Coq, not unchecked rewrite
instructions. Structural induction proves that every grammar word takes
one F step to its successor. The W3 proof applies the last context rule
twice, carries over m run-length-2 blocks, and invokes the child's F step.

The semantic bridge is a B right excursion. For every F derivation there
are finite witnesses a, r and c such that, for every untouched left context l:

```coq
csteps tm c (front B l w) = Some (back B l ((21)^a ++ 0::r))
v = (10)^a ++ 11r
```

Here w and v are the binary words before and after F. Finite terminal and
context rules are ordinary reduction proofs. The two recursive context
rules use explicit right-excursion composition and the supported crossing
program below. No coarse condition on run counts or tape alphabets is
assumed to imply a return.

The common read gate reaches B reading w with left support `Q^n G`, where
`Q=223` and `G=22323223132`, in `3n+34` steps. A three-step right scan
consumes each P and prepends Q. A separate finite 34-step program handles U
and the implicit blanks at the left boundary; both are universal context
lemmas.

The essential crossing is:

```text
B back (223 l), right (21)^a 0r
 -> B back l, right 00 (10)^a 11r
```

It takes `6a+9` steps for every a and arbitrary contexts l,r. A right scan
passes over the 21 train, a left scan passes over the resulting 31 blocks,
and finite turns restore the stated output. When a=0, a Q block is consumed
in nine steps, emitting 011 after a retained leading 0. Induction handles
any number of Q blocks. The fixed G boundary then reaches the left blank
in 31 steps. The identities `1(01)^a=(10)^a1` and
`11(011)^n=(110)^n11` give the required block orientations.

The supported gate for n>0 therefore takes `9n+6a+31` steps and reaches the
next main configuration with word `(10)^a11r`. Combining it with the read
gate and the grammar normalizer gives a positive return:

```coq
forall n g, exists d, 0<d /\
 csteps tm d (main (S n) (word g)) =
 Some (main (S (S n)) (word (next g))).
```

The exhibited duration is `12n+65+c+6a` when the starting block count is
n>0 and c,a come from the finite normalizer witness. The theorem does not
assume a bounded normalizer runtime or a closed cost formula.

Starting from the actual step-234 entry, positive returns give arbitrarily
late A visits. The following step always enters B. Thus both states recur.
Totality proves nonhalting, and both-state recurrence gives `QHBound 0`.
The older conditional finite-algebra package is not imported and remains
unchanged.

The unrestricted alternative grammar of 32/322 blocks ending in 3132 is
false. The synthetic word 3223132 reaches B scanning blank with an empty
right word after 51 steps, and then B0 continues right forever. This case
is included as a concrete negative grammar control. Removing the fixed G
support also invalidates the supported gate.

Thirty-seven Coq regressions cover the actual entry, zero and positive
train gates, read gates, every constructor normalizer and return, a deeper
recursive return, the false broad grammar, missing support, and exact A3/B3
transition identities. The 29,538 native controls independently replay 942
grammar trees through depth two, counters through two in each wrapper,
left/right contexts through length two, all crossing programs and main
returns, actual entry and 32 consecutive actual returns. Wrong A3 target
and B3 direction controls invalidate the claimed cycle. These finite
controls provide no universal proof credit.
