# S016: a closed a/d token-prefix grammar

This isolated package proves `NonHalt` and `QHBound 0` for exact frozen S016:

```text
1LB0RA0LB2RB_3RB3LA1RA1RA
```

Its complete code vector is `[5;2;1;11;15;12;6;6]`, with census code
2625202922. The native checker independently decodes frozen row 16. The
Coq wrappers prove complete-table equality, the state bound for every
completion, exact singleton census membership, and previous pending status.
The prior remaining-3 list is a pinned snapshot; this package does not
change the tracker.

Use nearest-first left tokens:

```text
a=13312     b=012     c=312     d=13313312.
```

The generic `Normalizer.v` is a byte-identical copy from the frozen sibling
foundation, SHA256
`4b43d3e48f8ea0fd874c2d357c7741dc0650213944537d03e16f682c5ebf57cf`.
It is compiled under this package's own namespace. Formal replay checks the
local copied source against that fixed hash; it requires no historical
Normalizer object, report, or parent source path.

The shared transformation on arbitrary finite token lists is:

```text
F([])=ab       F(a x)=a F(x)       F(b x)=d x
F(c x)=b F(x)  F(d x)=aac x.
```

The shared normalizer is universal over all three sibling B2 transitions.
B at the back of `enc(x)3`, with right word `0·31313·r`, reaches A3 with
left word `enc(F(x))3` and untouched right continuation r. Its exact cost
is `30` at the empty word, `38+cost(x)` for a, `10` for b,
`26+cost(x)` for c, and `46` for d. The terminal left 3, with the blank
half-tape beyond it, is an explicit guard.

Only `bn_RightOne` is selected for the S016 classification. In particular,
B2 writes 1, moves right, and enters A. The common all-variant theorem does
not identify this table with S014 or S015.

Write `C(x)` for A0 with blank right tape and left word `enc(x)3`.
The closed grammar is:

```text
x=a ts or x=d ts, for an arbitrary finite token list ts.
```

The exact blank run reaches `C(ab)` in 56 steps. The universal closure
statement is:

```coq
forall ts, b16_valid ts -> exists k ys,
 0<k /\ b16_valid ys /\
 csteps b16_tm k (b16_C ts) = Some (b16_C ys).
```

For example, the actual first guarded return is `C(ab)->C(acad)` in
454 steps. Arbitrary a/d tails are admitted by the theorem, rather than
being inferred from the finite controls.

The closure proof uses finitely many continuation states, all with left
word `enc(x)3`. B-back states have these fixed right words:

| State | Right word |
| --- | --- |
| H(x) | 03131 |
| L(x) | 03031 |
| M(x) | 0303131 |
| K(x) | 0333031 |

There are also A3 with right word 1, and `C12(x)` with left prefix 12
before `enc(x)3`. An elementary case analysis proves that every F image is
nonempty and starts with a, b, or d. This image guard closes the continuation
states in the following order:

1. H(a x) normalizes x and reaches C(a F(x)); H(b x) reaches C(d x);
   H(d x) reaches C(aac x).
2. L(a x) reaches H(F(x)); L(b x) reaches C(ac x); L(d x) normalizes
   x and reaches C(ab F(x)). Thus L(F(x)) always returns to the grammar.
3. C12 with leading a or b normalizes the tail and reaches L of an F
   image. Its d case reaches L(ac x), covered by the preceding a case.
4. A3 with right word 1 and an F image on the left reaches C12 of another
   F image, or reaches a guarded cut directly.
5. M on an F image reaches the preceding A3 or C12 cases.
6. K on an F image reaches M of an F image or a guarded cut directly.

This dependency order is finite. No continuation lemma assumes its own
return or a future grammar result. Every unbounded token scan is the
shared structural normalizer; the remaining headers are ordinary Coq
reduction proofs with arbitrary unread left context.

Two main headers finish the closure. `C(a x)` takes `123+cost(x)` steps
to K(F(x)). `C(d x)` takes `269+cost(x)+cost(F(x))` steps to
C12(b F(F(x))). The first header durations are strictly positive. Combining
each with its proved continuation gives the positive universal closure
above; a closed overall cost formula is unnecessary.

The K(d x) continuation has a separate exact guard. Its 98-step header
leaves `0·31313·313303131` on the right. After normalizing x, a 115-step
header and another normalization reach a six-step finish, then two short
headers return to `C(ac F(F(x)))`. This branch costs
`243+cost(x)+cost(F(x))` steps. The similar string 313103131 is not this
continuation; an explicit negative regression prevents substituting it.

Positive guarded returns give arbitrarily late A visits. Every main cut
scans 0 in A, and its next step is in B, so B also recurs. Totality proves
nonhalting, and both-state recurrence proves `QHBound 0`.

The 41 Coq regressions cover all leading-token normalizer cases, both
main-prefix cases with every leading tail token, actual blank entry,
continuation boundaries with independent left contexts, the corrected
K(d) continuation, a missing-terminal-marker negative case and exact B2
identity checks. The 22,885 native controls independently replay all 34
finite programs, 21,483 normalizer cases across all three variants,
682 guarded a/d returns, entry and 16 consecutive actual returns, plus
negative continuation and wrong-table controls. They supply no universal
proof credit.
